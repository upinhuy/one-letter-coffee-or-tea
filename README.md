## The answer

Coffee or tea — the whole debate settled in a single letter. This program
writes exactly one character to `/output/entry.txt`:

```
A
```

`A` stands for coffee. No words, no explanation, no punctuation — just the
letter, because in the coffee-versus-tea argument, coffee needs no warm-up
act. It arrives first, hits hardest, and wakes you up before the argument
even starts.

## How it works

`main.ts` (Node 22, no dependencies) creates `/output` if needed and writes
the single byte `A` to `/output/entry.txt`, with no trailing newline.

```sh
node main.ts
```
